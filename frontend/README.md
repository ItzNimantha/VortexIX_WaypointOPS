# Frontend (React)

Because this application was built using **Next.js 14 App Router** (a modern full-stack framework), the frontend and backend are elegantly unified to provide server-side rendering (SSR) and seamless API integration.

All frontend React code, UI components, and layouts are located in the following directories in the root of the repository:
- `../src/app/` (React Server & Client Components)
- `../src/components/` (Shared UI Components)
- `../src/styles/` (Tailwind CSS styling)

This unified structure is the industry standard for Next.js applications and provides significantly better performance than a separated Single Page Application (SPA).
