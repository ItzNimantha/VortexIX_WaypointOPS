# seed-data

Official competition CSVs used by the app seed (`prisma/seed.ts`). **Confidential: do not publish or share.** Keep this repo private.

| File | Used for |
|---|---|
| outlets.csv | 120 outlets |
| vehicles.csv | 60 vehicles |
| calendar.csv | operating days, paydays, festivals, monsoon |
| district_travel.csv | trip-time calculation |
| service_allowance.csv | handling time per brand + dock type |
| task2b_peak_day_scenarios.csv | seeded S1 peak-day orders (85) |
| task2b_peak_day_fleet.csv | S1 vehicle availability (10 in workshop) |
| submission_task2b_TEMPLATE.csv | shape of the Task 2B export |

Datathon training/test files are intentionally NOT in this repo.
